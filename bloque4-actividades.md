# Actividades prácticas · Bloque 4
{: .fs-8 }

**Escoge una o dos propuestas**, adaptadas a tu etapa y especialidad. No es necesario realizar las seis. Puedes reutilizar lo creado en bloques anteriores. Entrega un producto revisado y una justificación breve.

## 4.1 · Instrumentos de evaluación

Crea **dos** entre rúbrica, lista de cotejo, autoevaluación o cuestionario: define tarea y criterio oficial; pide borradores a la IA; revisa claridad, observabilidad, adecuación y sesgos.

```text
Para [ETAPA, CURSO, MATERIA], y este criterio oficial que aporto:
[CRITERIO Y FUENTE], crea dos instrumentos entre rúbrica, lista
de cotejo, autoevaluación y cuestionario. Usa lenguaje adecuado,
indicadores observables y comentarios de mejora. No inventes normativa.
```

**Ejemplos:** Infantil: observación del juego y caritas; Primaria: exposición y cuestionario; ESO: investigación y autoevaluación; Bachillerato: texto argumentativo y rúbrica; FP: práctica técnica y checklist; EOI: interacción oral y autoevaluación.

**Entrega:** dos instrumentos y por qué sirven para esa tarea.

## 4.2 · App interactiva y Aules

Diseña un cuestionario, juego o miniaplicación HTML con pistas, explicaciones y posibilidad de repetir. Comprueba respuestas y accesibilidad. **Publica o exporta** y elige una vía permitida en tu centro: recurso URL (preferible), iframe autorizado o archivo HTML probado. El iframe puede estar filtrado; HTML con JavaScript puede no ejecutarse y los resultados no se sincronizan por defecto con las calificaciones de Moodle.

```text
Crea un index.html responsive y accesible, sin dependencias ni
recopilación de datos, para [ETAPA/TEMA]: 5 preguntas, pista,
explicación del error, reintento y reinicio. Verifica respuestas.
```

**Ejemplos:** Infantil: clasificación guiada; Primaria: cuerpo humano; ESO: ciencias; Bachillerato: falacias; FP: seguridad laboral/técnica; EOI: vocabulario contextualizado.

**Entrega:** archivo o enlace funcional y explicación de acceso desde Aules.

## 4.3 · Personalización con DUA

Elige un material; detecta una barrera; propón ajustes en **implicación, representación y acción/expresión**, sin cambiar injustificadamente objetivos ni criterios. Compara original y versión accesible.

```text
Rediseña este material para [ETAPA] según CAST DUA 3.0.
Meta que se mantiene: [..]. Original: [..]. Barreras: [..].
Ofrece opciones de implicación, representación y acción/expresión.
Devuelve material adaptado y tabla barrera → cambio → justificación.
```

**Ejemplos:** Infantil: secuencias visuales; Primaria: glosario y esquema; ESO: texto escalonado; Bachillerato: andamiaje argumentativo; FP: instrucciones visuales para práctica; EOI: apoyos léxicos según objetivo.

**Entrega:** original, rediseño y explicación de barreras resueltas.

## 4.4 · Detectives de errores: el alumnado corrige a la IA

**[Probar la aplicación interactiva «Detectives de IA»]({{ '/detectives-ia/' | relative_url }})** · Biología y Geología, 3.º ESO. Diez afirmaciones, cinco errores, pistas, correcciones y posibilidad de repetir. El solucionario se mantiene en la guía del profesorado de la V2.


Prepara una respuesta con tres errores **verificables**; el alumnado debe detectar, contrastar, corregir y justificar. Incluye un solucionario separado para el docente.

```text
Crea para [ETAPA/MATERIA] una explicación ficticia sobre [TEMA]
con exactamente 3 errores verificables. Separa texto para alumnado
de solucionario docente con justificación, fuente fiable y preguntas.
No inventes referencias.
```

**Ejemplos:** Infantil: imagen con elemento incoherente; Primaria: planetas; ESO: respiración; Bachillerato: argumento histórico; FP: procedimiento simulado; EOI: correo con errores de registro.

**Entrega:** material para el alumnado, solucionario verificado y uso previsto.

## 4.5 · Una tarea donde la IA no sustituya el aprendizaje

Transforma «hacer un resumen» en una tarea que muestre **observación, proceso, decisiones y explicación personal**.

```text
Rediseña [TAREA] para [ETAPA] permitiendo IA como apoyo,
pero exige evidencias propias: observaciones, borradores, datos,
decisiones o defensa. Muestra antes → riesgo de delegación →
después, criterios y usos permitidos de IA.
```

**Ejemplos:** Infantil: observar una planta y contarlo; Primaria: contar residuos reales; ESO: experimento con registro; Bachillerato: ensayo con borradores y defensa; FP: pruebas de un montaje; EOI: conversación improvisada y reflexión.

**Entrega:** actividad antigua, rediseño y evidencias que valorarás.

## 4.6 · Crea tu propio asistente docente

Diseña un prompt reutilizable (o GPT/Gem si dispones de esa función) para una tarea repetida: rúbricas, adaptaciones, cuestionarios o feedback. Pruébalo y mejora sus instrucciones.

```text
Eres mi asistente de [TAREA] para [ETAPA/MATERIA].
Pide solo datos necesarios; usa criterios oficiales que yo aporte.
Genera borrador, revisa accesibilidad y señala dudas.
No inventes normativa ni uses datos personales. Entrega [FORMATO].
Prueba con un caso ficticio y sugiere una mejora.
```

**Ejemplos:** Infantil: consignas accesibles; Primaria: rúbricas; ESO: preguntas de repaso; Bachillerato: argumentos; FP: checklist técnico; EOI: simulaciones de diálogo.

**Entrega:** nombre, instrucciones, prueba y mejora.

## Proyecto final simplificado

Presenta **un producto de cualquier bloque** y contesta brevemente: contexto, proceso, producto y reflexión/aplicación. Admite documento, app, enlace, vídeo, audio, infografía o asistente; **sin extensión mínima**.

**Recuerda:** usar ejemplos ficticios, comprobar fuentes y mantener la decisión evaluativa en manos del profesorado.
